# 窗口游玩记录与截图索引

本轮通过真实 Windows 游戏窗口按键，截图均为窗口原始 JPEG。报告正文记录问题、反馈和修改，本文件按场景列出实际操作与全部截图。

## 原版画面与输入

1. 启动默认棋盘并观察撞墙结果。
2. 中文输入状态按 P，看到候选框。
3. 取消候选并切到英文后按 P，蛇停住但仍显示 PLAYING。

## 新版默认棋盘

运行参数：`python snake/main.py`

1. 观察 READY 等待画面。
2. 空格开始并撞墙。
3. 回车重玩。
4. 反复按减号，速度降至 2.0/s。

## 新版连续游玩

运行参数：`python snake/main.py --width 110 --height 24 --seed 242`

1. 17 次减号调至 2.0/s。
2. 空格开局，吃到食物，Score=1、Length=4。
3. 空格暂停并间隔后复查。
4. 上方向键，空格恢复，再暂停。
5. 左方向键，空格恢复，再暂停。
6. 按 = 加速至 2.1/s。
7. Esc 退出，游戏返回 0。

## 新版中文输入环境

运行参数：`python snake/main.py`

1. 切换输入环境后按 P，观察中文候选框。
2. Esc 取消候选，保留该输入环境。
3. 减号调速，空格开始和暂停。
4. 上方向键后空格恢复，看到竖直移动，再暂停。
5. Esc 退出，游戏返回 0。
